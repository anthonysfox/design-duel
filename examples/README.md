# Example output

These are the files Design Duel writes during a session, from a made-up repo called **linkly**: a small URL shortener with a Node API, Postgres and a click counter.

| File | What it shows |
| --- | --- |
| [`log.md`](log.md) | The session log: verdict per problem, where the player got stuck, what they figured out alone |
| [`fixes.md`](fixes.md) | The fix log: bugs and improvements found in the repo along the way |
| [`talking-points.md`](talking-points.md) | Interview mode output, written in first person from the session |

The real files live in `~/.design-duel/<repo-name>/` on your machine, never inside your repo. `map.md` (the answer key) isn't shown here, since it's only for Claude.
